# Tennis algorithm lab — planned

A roadmap for improving tennis activity detection using reviewed cut-quality
feedback. This repository currently contains planning material only. It does not
implement feedback capture, model training, or a replacement detector.

See [the roadmap](ROADMAP.txt). The current published website lives in
[tennis-web](https://github.com/haocs/tennis-web).

Keep recordings, precise locations, private configuration, and feedback datasets
outside Git. Any future shareable fixtures should be synthetic or explicitly
approved for redistribution.
